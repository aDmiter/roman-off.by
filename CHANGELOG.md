# Changelog

Все значимые изменения проекта ROMANOFF FIGHT CLUB.

## [Unreleased]

### Лендинг (`/`)
- Одностраничник: Header, Hero (фон `hero_bg.jpg`, 100vh), «Твой тренер» (фото), Направления, Расписание (из админки), Преимущества, Цены (табы), Соцпроект «Сильная молодёжь», Контакты (форма + Яндекс-карта), Footer.
- Тёмно-золотая тема, шрифты Oswald/Roboto, прелоадер с лого и полосой загрузки.
- SEO-мета (title/description/keywords), favicon и лого из `public/uploads`.

### Админка
- **Вход:** email + пароль (scrypt), сессия в `AdminSession`, cookie `rfc_session`. Суперадмин: `Centrfightbrest@gmail.com`. Guard в `admin/layout.tsx`.
- **Обзор:** приветствие + быстрые ссылки.
- **Тренеры:** имя, специализация, загрузка фото, цвет для календаря.
- **Клиенты (CRM):** имя/фамилия, фото, телефон (обяз., уник.), email, дата рождения, любимый тренер; карточка-профиль с вкладками Обзор (статистика), Посещения (история), Абонементы (история), редактирование; поиск по базе.
- **Календарь (FullCalendar):** тёмная тема, сетка 08:00–22:00, месяцы/недели/дни/список, фильтр по тренеру. Создание записи: тренер → занятие → дата → свободные слоты (шаг 30 мин в рамках времени работы дня) → конец = начало + продолжительность.
- **Расписание:** недельные шаблоны занятий (показываются на лендинге).
- **Заявки:** заявки с формы лендинга.
- **Абонементы:** генерация кода `RFC-` + 10 цифр, штрихкод Code128 (PNG), привязка к клиенту, печать карточки.
- **Сканирование:** камера (ZXing) + ручной ввод с маской `RFC-`; поиск абонемента и списание занятия (при привязке к клиенту пишется `Visit`).
- **Настройки:** «Занятия» (название + продолжительность, CRUD) и «Время работы» (7 дней, 08:00–22:00, редактирование).

### Бэкенд
- Prisma-модели: `AdminUser`, `AdminSession`, `Coach`, `Client`, `Visit`, `Training`, `Session`, `Booking`, `Membership`, `MembershipUsage`, `LessonType`, `WorkingHours`.
- REST API: `auth`, `admin`, `coaches`, `clients` (+ visits), `sessions`, `trainings`, `bookings`, `memberships` (+ use/scan), `lesson-types`, `working-hours`, `upload`, `files`.
- Загрузка медиа в `public/uploads`, раздача через `/api/files/[name]`.
- Сид: суперадмин, 3 тренера, 8 тренировок, демо-клиент, демо-абонемент, 4 типа занятий, 7 дней рабочего времени.

### Известные особенности
- Сборка в песочнице агента на диске `D:` может падать из-за `EPERM` (ограничение окружения, не кода). См. `AGENTS.md`.
